# Final Project Brief

GroundStack is a portfolio-grade AI technical-support app for developer communities. It ingests
technical docs, retrieves relevant evidence with hybrid search and reranking, streams grounded
answers, validates citations, and records evaluation/feedback artifacts for review.

The project demonstrates backend/platform engineering, applied AI safety, release discipline, and
honest evidence handling. It includes a Discord slash-command adapter, but does not claim a live
public Discord deployment.
