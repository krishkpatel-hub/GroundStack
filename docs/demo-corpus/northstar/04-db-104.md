# Northstar Systems Database Error DB-104

Category: Database Support
Version: NS-DB-1.7
Updated: 2026-08-18
Demo note: Northstar Systems is a fictional organization for the GroundStack portfolio demo.

## Meaning

`DB-104` means the application could connect to the database host but failed the schema readiness check. The most common cause is a missing migration on the target environment.

## Immediate Resolution

1. Confirm the service is pointing at the intended database using `NORTHSTAR_DB_ENV`.
2. Run the migration status command: `northstarctl db status --env <environment>`.
3. If pending migrations are listed, run `northstarctl db migrate --env <environment> --ticket <change-ticket>`.
4. Restart the affected service after the migration completes.
5. Confirm the health check reports `schema_ready=true`.

## Safety Checks

Do not drop tables or manually edit the schema to resolve `DB-104`. If migration `2026_08_14_add_case_queue_index` fails, escalate to Database Support with the migration log and change ticket.

## Related Signals

- API health detail: `schema_ready=false`.
- Application log key: `db.schema_check.failed`.
- Runbook label: `NS-DB-104-SCHEMA-READINESS`.
