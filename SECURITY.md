# Security Policy

Report suspected vulnerabilities privately to the repository owner. Do not open public issues for
secrets, auth bypasses, prompt-injection exploits against private data, or deployment weaknesses.

GroundStack currently supports provider-neutral OIDC authentication, admin route boundaries, safe
defaults for demo mode, and local production artifacts. It is not yet a fully isolated multi-tenant
knowledge platform.

Never include access tokens, cookies, API keys, source documents, or private prompts in reports.
