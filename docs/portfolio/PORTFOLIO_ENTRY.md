# Portfolio Entry

## GroundStack

## Stack

Next.js, React, FastAPI, PostgreSQL, pgvector, SQLAlchemy, Alembic, Redis, Docker, sentence
transformers, Ollama/OpenAI-compatible generation, Locust, Playwright, Vitest, pytest.

- Admin ingestion and evaluation workflows.
- Human-reviewed training-candidate pipeline.
